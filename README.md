# METOSAN website

A static, responsive landing site for **METOSAN**, the macOS character metronome.

Target URL: **https://metosan.danbee.ai**

## Included

- `index.html` — responsive hero, hand-waving character illustration rendered in SVG, features, support contact, four-language toggle (KO/EN/JA/ZH).
- `support/index.html` — support information and contact email `contact@danbee.ai`.
- `privacy/index.html` — **temporary placeholder**. Replace it with an approved, accurate privacy policy before App Store submission.

## Publish

Deploy this repo as a static site to Cloudflare Pages, Vercel, Netlify, or GitHub Pages. No build step is required. Connect the custom DNS `metosan.danbee.ai` in the hosting provider.

## Before launch

1. Review product copy and feature accuracy against the released binary.
2. Replace the privacy placeholder with an approved policy based on actual application data flows.
3. Replace the Coming Soon Mac App Store label with the real store URL and an accessible hyperlink when available.
4. Check all four languages and mobile layout.
5. Use `https://metosan.danbee.ai/support/` for the App Store support URL and `https://metosan.danbee.ai/privacy/` for the privacy URL only after deployment and final policy approval.
6. Confirm deployed HTTPS, paths, and DNS.
